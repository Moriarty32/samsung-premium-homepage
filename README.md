# Online Samsung — premium homepage

Статическая адаптивная главная страница для демонстрации клиенту. HTML, CSS и JavaScript, без сборки и внешних библиотек в браузере.

- Демонстрация: https://moriarty32.github.io/samsung-premium-homepage/
- Репозиторий: https://github.com/Moriarty32/samsung-premium-homepage
- Публикация: ветка `main`, GitHub Pages.

## Слайдер категорий на первом экране — 9 ноября 2026

По запросу клиента первый экран теперь содержит три категории: смартфоны Galaxy, телевизоры и техника для дома. Каждый слайд имеет собственные изображение, текст и действия: графитовая сцена со смартфоном, тёмная сцена с большим телевизором и светлая сцена со стиральной машиной. В карточке категории «Техника для дома» восстановлен прежний файл `assets/product-washer.webp` из версии `9c2c73d`.

Новый рендер телевизора: `assets/hero-television.webp`, 1536 × 1024, RGBA, создан встроенным imagegen. Точный промпт и происхождение — в `assets/sources.json`. Все устройства помещаются в блоки целиком через `object-fit: contain`. Высота первого экрана остаётся одинаковой при переключении. На телефоне изображение располагается над текстом.

Управление: вкладки категорий, стрелки, клавиши Left/Right/Home/End, свайп и пауза. Автопереключение каждые 9 секунд останавливается при наведении, фокусе, открытом сравнении, скрытой вкладке, уходе блока с экрана и уменьшении движения. Неактивные слайды исключены из взаимодействия через `inert` и `aria-hidden`. Без JavaScript первый слайд остаётся видимым, неработающие элементы управления скрыты.

Скрипт требует чистой рабочей папки, восстанавливает **весь отслеживаемый снимок**, удаляет файлы, которых не было в прежней версии, и создаёт новый коммит. История сохраняется, `reset` и принудительная отправка не используются. После отправки нужно дождаться завершения GitHub Pages deployment. Скрипт входит в новую версию; после отката к старому снимку он также исчезнет из рабочей папки и останется доступным в истории Git.

Проверка механизма выполнена в отдельном временном Git-репозитории: восстановлены исходные файлы, удалены добавленные позже файлы, деревья `HEAD` и резервного тега совпали, история из трёх коммитов сохранена, рабочая папка чистая.

## Изображения и шрифты

Размеры, источники и точные промпты двух новых изображений: [`assets/sources.json`](assets/sources.json).

- `catalog-phone.webp` — реальный товарный рендер S26 Ultra, 1200 × 800, альфа-канал.
- `catalog-watch.webp` — реальный товарный рендер Watch Ultra, 1200 × 800, альфа-канал.
- `catalog-buds.webp` — реальное фото Buds4 Pro, 1200 × 1200.
- `fold-authentic.webp` — реальный рендер Fold7, 1200 × 800; исходный альфа-канал сохранён.
- `washer-authentic.webp` — реальный рендер Samsung Bespoke, 1200 × 800, альфа-канал.
- `campaign-cinema.webp` — новая рекламная интерьерная сцена, 2172 × 724.
- `journal-phone.webp` — новая рекламная обложка с идентичностью телефона по каталожному референсу.
- `journal-tv.webp` — отдельная иллюстрация из реального руководства по выбору телевизора.
- `ecosystem-cutout.webp` и `product-tv.webp` — иллюстративные композиции предыдущей версии, без заявления о точной комплектации набора или конкретной модели телевизора.
- `client-logo.svg` и SamsungSharp — фирменные материалы клиента.
- SamsungOne 400/700 — шрифты с официального сервера Samsung, локальные WOFF2.

Новые рекламные изображения созданы встроенным инструментом **imagegen**, без API-ключа и CLI. Оригинальные PNG сохранены в стандартной папке генерации Codex; используемые WebP находятся в проекте. Pillow применён для экспорта и сжатия, не для перерисовки устройств. Геометрия товарных изображений сохраняется через `object-fit: contain`; изображения окружения допускают художественное кадрирование. Поверхности разделов задаёт CSS, поэтому фоны изображений не создают прямоугольных полос на границах.

## Локальный просмотр и проверка

```powershell
python -m http.server 4173
```

Открыть http://localhost:4173. Сборка и установка зависимостей не требуются.

Проверено в Chrome с Playwright: ширины 320–2560 px, границы адаптивных режимов, загрузка изображений, переносы и переполнение текста, отсутствие горизонтального скролла, открытие/закрытие меню и поиска, диалог сравнения, клавиатурное управление вкладками, обычное и анимированное раскрытие FAQ, динамическое уменьшение движения, видимость контента без JavaScript. Внешние ссылки проверены GET-запросами: 30 уникальных адресов, все вернули HTTP 200.

Для изображений и CSS/JS используется версия URL. При следующем изменении стилей или поведения следует обновить параметр `v` в `index.html`, чтобы исключить старый кеш при демонстрации клиенту.
