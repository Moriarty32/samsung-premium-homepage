# Samsung — демонстрационная главная страница

Адаптивный статический макет по предоставленному референсу. Это демонстрация для клиента, а не официальный магазин Samsung. Цены повторяют референс и не являются актуальным предложением.

## Дизайн

Композиция повторяет последовательность блоков референса: большой продуктовый hero, три категории, баннеры Galaxy Z Fold и Neo QLED, популярные устройства, экосистема, сервисы, преимущества покупки, статьи, FAQ и футер. Светлые нейтральные секции чередуются с графитовыми рекламными сценами. Скругления и тени сосредоточены на карточках; крупные баннеры сохраняют чистую рекламную подачу.

Исследование опиралось на [страницу Galaxy S26 Ultra](https://www.samsung.com/ru/smartphones/galaxy-s26-ultra/) и [философию Samsung Design](https://design.samsung.com/global/contents/design-philosophy/): крупный продукт, короткий текст, выразительный контраст и ясная иерархия. Фотографии устройств созданы специально для макета и не претендуют на точное изображение серийных моделей.

## Изображения и адаптивность

В `assets/` лежат 9 оптимизированных WebP изображений. Основной hero имеет пропорции 1836×857; широкие баннеры — от 1850×617 до 1850×694; отдельные устройства — до 900 px по ширине. Браузер сохраняет пропорции: рекламные сцены используют `object-fit: cover`, а карточки устройств — `object-fit: contain`. Ключевые блоки перестраиваются на ширине 960 и 680 px. Анимации учитывают `prefers-reduced-motion`.

## Локальный запуск

```bash
python -m http.server 4173
```

Открыть `http://localhost:4173/`. Сборка и зависимости не требуются.
