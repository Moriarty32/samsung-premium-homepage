### Как выводятся статьи

На главной выводятся **две свежие публикации и один закреплённый полезный гид**. Актуальность определяется реальной датой публикации, а не именем файла. Сейчас это материал о One UI 9 от 6 ноября 2026, закреплённый гид по телевизорам и обзор Galaxy Tab S12.

Рабочий публичный импорт блога:

```powershell
node .\scripts\sync-journal.mjs --check
node .\scripts\sync-journal.mjs
node .\scripts\build-site.mjs
```

`--check` читает источник без записи. Импорт разбирает `/station`, удаляет дубли, сортирует 94 найденные статьи по `time[datetime]`, сохраняет последние шесть и локальные обложки в `data/journal-feed.json`. При ошибке структура опубликованной страницы и последний проверенный JSON сохраняются. Закреплённый гид, заголовки и замены обложек задаются в [data/home-editorial.json](data/home-editorial.json). Сборка берёт два самых свежих материала и закреплённый гид.

Для демонстрации используется импорт при сборке. Прямого запроса из браузера к чужой CMS нет: публичные AJAX-вкладки магазина не предоставляют нужный CORS-доступ. На действующем Drupal эти же подборки можно подключить к существующим блокам/Views и полям редакционного отбора. Закрытый API не предполагался; доступ к административной части магазина не использовался. Автоматический запуск по расписанию не включён.
