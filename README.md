# Online Samsung — концепт главной страницы

Адаптивный статический редизайн по предоставленному референсу для [online-samsung.ru](https://online-samsung.ru/). Это демонстрационная страница, а не действующий магазин. Цены взяты из референса и не являются офертой.

## Визуальный аудит

На сайте клиента изучены логотип, шрифты, размеры основных текстовых элементов, цвета верхних панелей и структура каталога. В макете используется его SVG-логотип и локальные файлы SamsungSharpSans Regular/Bold. Навигация набрана в 14 px, основной текст — в 16 px; крупные рекламные заголовки образуют отдельный масштаб. Синяя промопанель, тёмная служебная полоса и светлая основная навигация связывают редизайн с действующим сайтом.

Исправлены обнаруженные визуальные проблемы: изображения в карточках категорий теперь целиком помещаются внутри блоков, баннер Galaxy Z Fold не обрезает устройство, а для Fold, телевизора и экосистемы созданы отдельные вертикальные сцены. Между Fold и Neo QLED расположен светлый баннер экосистемы с полноценной предметной композицией. FAQ выполнен на согласованном жемчужно-белом фоне со световой дугой, карточками вопросов и контактом магазина.

## Изображения и адаптивность

В `assets/` лежат 14 оптимизированных WebP изображений. Новый баннер экосистемы подготовлен в размерах 1800×600 px и 900×1125 px; фон FAQ — 1800×600 px, изображение для контакта — 900×600 px. Изображения не растягиваются: на телефоне и планшете подрезается только пустое пространство мобильной композиции, все устройства остаются в кадре. Устройства в карточках размещены через `object-fit: contain`. Основные точки перестроения — 1100, 900, 760 и 680 px. Анимации учитывают `prefers-reduced-motion`.

Основные ссылки ведут в действующие разделы online-samsung.ru. Поиск по разделам, карусель, мобильное меню и FAQ работают локально без серверной части.

## Локальный запуск

```bash
python -m http.server 4173
```

Открыть `http://localhost:4173/`. Сборка и зависимости не требуются.
