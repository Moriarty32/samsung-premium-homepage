# Аудит содержимого главной online-samsung.ru

Проверено: 2026-11-09T12:49:56.679172+00:00. Источники — только публичные страницы [магазина клиента](https://online-samsung.ru/), его AJAX-вкладки, карточки товаров и [блог](https://online-samsung.ru/station).

## Фактическая структура

- «Новинки»: четыре вкладки — Мобильные, ТВ и аудио, Бытовая техника, Аксессуары. Каждая загружает пять карточек через `/spm/new/128`, `/130`, `/131`, `/129` соответственно.
- «Хиты продаж»: Все и те же четыре категории. Источники — `/spm/hits/all`, `/128`, `/130`, `/131`, `/129`. Десктопная и мобильная разметка частично дублируют SKU: импорт должен удалять повторы.
- «Товары дня»: Slick-карусель из **17** карточек, а не три единственных товара. Для редизайна выбраны первые три: Tab S12 Ultra 512 ГБ, Galaxy A18 256 ГБ серый и Watch Ultra 2 чёрный титан. Полный исходный список сохранён в `sections[id=daily].products`.
- В проверенной разметке «Товаров дня» не обнаружены дата завершения и достоверный таймер. Добавлять обратный отсчёт нельзя.

## Подборка и изображения

- JSON содержит **31 уникальный SKU**. В каждой вкладке «Новинок» и каждой категорийной вкладке «Хитов» — три товара; в «Все» — четыре. Принадлежность проверена по точному SKU, не по похожему названию модели.
- `products` индексируется SKU в нижнем регистре, `product.sku` записан прописными буквами. `shortName` содержит только модель; конфигурация находится в `variant`.
- Пять дополнительных товаров из каталога сохранены для существующих разделов сайта. Их `clientSections` пуст: они не объявлены новинками или хитами клиента.
- Сохранены 23 новых чистых официальных ракурса и шесть изображений статей. Восемь фотографий переиспользуют ранее проверенные локальные галереи.
- Промо-постеры с текстом, гарантийные плашки и рекламные надписи исключены. Все 31 финальные фотографии товаров просмотрены визуально. WebP сохраняет исходные пропорции и весь холст.
- `image.bounds` — `{x,y,width,height}` в исходных пикселях; `image.alpha` отражает фактическую прозрачность. Это измерения, а не выполненная обрезка. На белом фоне выбирать `object-fit: contain`, согласовывать масштаб по видимому предмету.
- У **VS90F40DFGEV** и **WW11CB944CGHLP** на первых официальных фото есть отметка «Витринный образец». В JSON сохранён `conditionNote` со ссылкой-доказательством. Для карточек выбраны другие официальные чистые ракурсы без изменения изображения. Состояние экземпляра необходимо учитывать в подписи/предложении.

## Цены и предложения

Текущая цена получена из `drupalSettings.mindboxData.price` каждой карточки; цена до скидки — только из `.good-page__price-old`, если она явно больше текущей. Условные предложения Trade-in, покупка второго устройства и бонусы не превращались в прямую скидку. Сроки акций не придуманы. Снимок требует обновления перед реальными продажами.

## Публичный механизм импорта

В HTML видны `drupalSettings`, `use-ajax`, библиотеки `commerce_product`/`commerce_cart`, а `/spm/...` возвращает массив команд Drupal AJAX с `insert` и HTML. Это подтверждает Drupal и публичный механизм вкладок; точная версия CMS и документированный REST API не установлены.

Проверенные AJAX-адреса:

- [Новинки: Мобильные](https://online-samsung.ru/spm/new/128).
- [Хиты: Все](https://online-samsung.ru/spm/hits/all).

В проверенном ответе `/spm/new/128` с Origin GitHub Pages заголовок `Access-Control-Allow-Origin` отсутствует. Надёжный вариант для статического демо — импорт на сервере или при сборке и публикация локального JSON. Прямой браузерный fetch с другого домена не следует считать рабочей интеграцией.

Селекторы для блога:

```text
GET https://online-samsung.ru/station
card: article.catalog-news__item
url: a.catalog-news__item-link[href]
title: h3 (резерв: title у ссылки)
date: time.catalog-news__item-date[datetime]
thumbnail: .catalog-news__item-img img[src]
```

URL изображений и ссылок разрешать относительно домена клиента. Удалять повторы по URL, сортировать ISO-дату по убыванию, брать шесть. `.banner-news__item` не добавлять второй раз. RSS/Atom discovery link в проверенном HTML не объявлен; закрытая CMS-интеграция не использовалась.

## Рекомендации для реализации

1. Показывать переключатели без скачков высоты блока; три карточки в строку на десктопе, прокрутка/перестроение на мобильном.
2. «Новинки», «Хиты» и «Товар дня» выводить из отдельных подтверждённых коллекций JSON. Один SKU может встречаться в нескольких блоках, как у клиента.
3. Отделить короткую модель от конфигурации; фактический SKU, цены и ссылки сохранять.
4. Использовать единый нейтральный фон карточек, полные официальные ракурсы и одинаковую оптическую высоту техники; не растягивать фото.
5. Скидку показывать только при наличии подтверждённой прежней цены. В блоке дня оставить обычное предложение без искусственного таймера.
6. Публиковать дату последнего обновления данных и регулярно обновлять локальный снимок; при покупке вести на действующую карточку клиента.
